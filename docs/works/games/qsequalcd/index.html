QS=CD

Project Survival Card Game for iOS

概要 / Overview

日本語: QS=CDは、期間型のソフトウェア開発プロジェクトを題材にしたソロカードゲームです。
English: QS=CD is a solo card game inspired by fixed-term software development projects.

日本語: プレイヤーはPMとしてチームを率い、目標スコア、コスト制約、期限を確認しながら、プロジェクトが破綻する前の完了を目指します。
English: You lead a team as the project manager and try to complete the project before it collapses while managing score targets, cost limits, and deadlines.

コンセプト / Concept

日本語: 品質は固定。動かせるのは、スコープと現実だけ。
English: Quality is fixed. Only scope and reality can move.

日本語: 「QS=CD」はスコアの計算式ではなく、成果だけをコストやデリバリーから切り離して要求することはできない、という本作の設計思想を表します。
English: “QS=CD” is not a score calculation formula. It represents the game's principle that outcomes cannot be separated from cost and delivery.

ゲームの流れ / Gameplay

  1. 日本語: 目標スコア、コスト制約、残りラウンドを確認します。
    English: Review the score target, cost limit, and remaining rounds.
  2. 日本語: カードを公開する前に、PMとして行う介入を計画します。
    English: Plan your PM interventions before revealing the cards.
  3. 日本語: カードを公開し、成果や離脱などの結果に対応します。
    English: Reveal the cards and respond to outcomes such as results and team departures.
  4. 日本語: スコア、コスト、期限を満たせるタイミングでプロジェクトを完了します。
    English: Complete the project when you can satisfy its score, cost, and delivery constraints.

ゲームモード / Game Modes

  • シングルゲーム / Single Game
  • 大型プロジェクト / Large Project
  • 継続ゲーム / Continuation Game

日本語: 操作と判断の流れを実際に遊びながら確認できるチュートリアルも用意しています。
English: An interactive tutorial is also available to teach the controls and decision-making process.
